הגדרת חוקי אבטחה ב-Firestore ודומיינים מורשים

1. חוקי Firestore Rules: ב-Firebase Console עברו ל-Firestore Database → Rules והדביקו את הכללים הבאים. הרשאה ניתנת לשני החשבונות המוגדרים בלבד:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isCoupleAdmin() {
      return request.auth != null && request.auth.token.email in [
        'reemkayzer@gmail.com',
        'mayaco21@gmail.com'
      ];
    }

    match /settings/wedding {
      allow read: if true;
      allow write: if isCoupleAdmin();
    }

    match /guests/{guestId} {
      allow read: if true;
      allow create, delete: if isCoupleAdmin();
      allow update: if isCoupleAdmin() || (
        request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly(['status', 'confirmedCount', 'notes', 'rsvpUpdatedAt'])
      );
    }
  }
}

2. הפעלת התחברות אימייל/סיסמה:

ב-Firebase Console עברו ל-Authentication → Sign-in method והפעילו Email/Password.

לאחר מכן הוסיפו ב-Authentication → Users את שני החשבונות: reemkayzer@gmail.com ו-mayaco21@gmail.com.
